# 🛡️ SOC Tools - Built on iPhone

From NOC to SOC. 3 Python security tools built entirely on iPhone - no laptop, no excuses.

Author: Roland Benjamin | NOC Engineer → Aspiring SOC Analyst | Lagos, Nigeria
LinkedIn: https://www.linkedin.com/in/roland-benjamin-6324ab440

## 🔍 1. Log Hunter - log_hunter.py
Detects brute-force attacks from auth logs. Flags IPs with 3+ failed attempts.

Run it:
python3 log_hunter.py

## 🎣 2. Phishing Detector - phishing_detector.py
Scores URLs for phishing risk (0-100). Checks IP in URL, suspicious keywords, shorteners.

Run it:
python3 phishing_detector.py

## 🔐 3. Password Checker - password_checker.py
Checks password strength like SOC password policy. Checks length, uppercase, lowercase, numbers, symbols.

Run it:
python3 password_checker.py

## 🚀 Why I Built This
I work in NOC. I want to work in SOC. Instead of waiting for a laptop, I started building the tools SOC analysts use every day.
